# Onion Flows — pacote local (sandbox) — ultima versao

Versao publicada: 5.3.6

## Requisitos
- Windows 10/11
- Node.js 20+ (https://nodejs.org) com npm
- Portas livres: 3101 (API) e 30999 (frontend)

## Como rodar
1. Extraia este zip ou clone o repositorio
2. Execute START.bat; a configuracao local sera criada e validada automaticamente
3. Abra http://127.0.0.1:30999

## Logins
- Super admin: admin / sandbox123
- Agente: agent / sandbox123

## URLs
- Frontend: http://127.0.0.1:30999
- API: http://127.0.0.1:3101
- Seed: POST /api/load-test/seed-client

## Genesys (fases 1-4)
- Extensao → app: ext:atendimento:*
- App → extensao: cmd:enviar_mensagem, cmd:enviar_midia, cmd:encerrar
- Ack: cmd:resultado
- Conectar extensao com auth.client = "genesys-extension"
Ver: integracao-genesys-onionflows.md

## Parar
STOP.bat
